# Cerebrum

Agent-maintained project memory. Record entries as bullets, written
telegram-style — drop articles and hedges, keep paths, identifiers, and error
strings verbatim. End each bullet with its date, `(YYYY-MM-DD)`, and cite code
by backticked repo path and symbol name, not line number. Keep it lean:
consolidate or prune sections when they grow bloated or stale.
